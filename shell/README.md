# Raily Pin shell

3D models of the Raily Pin shell for the XIAO nRF52840 (Sense) with the
XIAO Expansion Board, a 602030 LiPo cell and a coin vibration motor.

The print files are in [`../published/keyring/`](../published/keyring/)
(the DA7280 edition: `raily-keyring-case.zip`); this folder holds only the
licence. Design constraints for the shell:

- a USB-C opening that takes a full-size plug;
- a ~1.5 mm paperclip hole over the RESET button (double-tap opens the
  flashing drive);
- translucent material (or a light pipe) so the status LED shows.
