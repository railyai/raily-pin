# Raily Pin assembly guide

The printable assembly guide (parts, soldering the button, the motor and
the LiPo, fitting the shell) is published with the first public firmware
release and is also linked from [atlas.railyai.com](https://atlas.railyai.com).
Flashing is covered by the AI-agent instructions in [`../flash.md`](../flash.md)
and the by-hand page [`../docs/manual-flash.md`](../docs/manual-flash.md).
